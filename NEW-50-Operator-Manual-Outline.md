# NEW-50 – Operator Manual Outline

1. **Introduction:** purpose, supported devices, prerequisites and role/permission model.
2. **Sign-in:** open app, sign in, session expiry, sign out, access denied/account disabled.
3. **Dashboard:** assigned machines/slots, low-stock, near-expiry/expired alerts, machine status.
4. **Product and price:** search by name/SKU, view details, update price when permitted, review audit.
5. **Slot assignment:** select machine/slot/product, check capacity/current stock, confirm assignment.
6. **Restock:** enter product, batch code, received date, expiry date and quantity; confirm and verify stock.
7. **FIFO and expiry:** explain oldest eligible batch first; expired/quarantined batches are blocked.
8. **Alerts and machine status:** acknowledge inventory alerts; view temperature/door history supplied by TV4; escalate hardware faults to TV4.
9. **History and audit:** search stock movements and operator actions.
10. **Troubleshooting:** invalid SKU, slot conflict, invalid expiry date, insufficient stock, API unavailable, permission denied.
11. **Support and change log:** support contact and release history to be supplied by the project team.
